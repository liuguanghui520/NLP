# 方向 C 课程项目要求摘录

自然语言处理课程  2026—2027 秋季学期

已选方向：提示 vs 微调对比。项目须围绕完整的小型 NLP 流水线展开，包含非大模型基线、大模型方案以及两者的对比评估。以下按项目定位、评分标准、交付物及相关报告要求整理。

## 一 项目定位

课程：自然语言处理；授课对象：软件工程专业三年级本科生；主讲：郭贵冰。项目共 45 分，占课程总评 45%；2—4 人一组，建议 3—4 人；不设答辩。

### 通用定位

用一条完整的小型 NLP 流水线，把课程里学过的方法真正用起来：数据 → 方法 → 评估 → 错误分析。外壳是大模型应用，内核是课程方法。每个项目必须包含：① 一个非大模型基线；② 一个大模型方案；③ 两者的对比评估。

评分关注四件事：有没有基线对比、有没有评估数据、有没有把失败讲清楚、别人能不能复现。任务书强调：7B 模型加完整评估与诚实分析，优于使用 70B 模型却只给出一个分数。

每个项目的报告必须用自己实验的证据解释至少 3 个课程原理点；只复述概念不算，必须有实验或数据支撑。任务书可选原理点完整列于末页。

### 两条硬门槛

跑不通＝项目不及格：教师或 AI 按 README 无法复现主结果的，允许 48 小时内补交环境说明或修复；补交后仍无法跑通的，第③项记 0 分，总分不超过 25 分。

报告与代码 / 日志对不上：报告中的关键数字在代码、日志或输出文件中找不到出处的，第④项减半；编造实验数据按学术不诚信处理。

### 三个拉开分差的地方

① 主动写出失败案例与局限，至少 3 个，逐一归因。
② 有参数对比实验并给出结论，任务书举例包括 top-k、chunk 大小、LoRA 秩、不同模型。
③ 能说清成本与延迟，包括 token 花费、响应时间。

### 压缩包规范

格式与数量：仅限 zip，只交 1 个压缩包。不收 rar、7z、分卷压缩，不要把材料拆成多个包。

体积与外链：单个文件 ≤50 MB；模型权重、录屏、数据集一律不进包，只给链接。

命名：组长学号_姓名_项目名.zip。网页示例：20246130_张三_公告要素抽取.zip。

包内结构建议：报告.pdf、项目摘要.md、README.md、src/（全部源码）、贡献声明_学号_姓名.md（每人一份）。

严禁打进包：虚拟环境、checkpoint、API Key、个人隐私数据。

## 四 报告结构与图表要求

项目报告正文 8—12 页，不含附录；以下为任务书各节建议篇幅。

| 章节 | 内容要点 | 建议篇幅 |
| --- | --- | --- |
| ① 问题定义与背景 | 解决什么问题、给谁用、成功判据是什么、为什么值得做。 | 0.5—1 页 |
| ② 相关工作与方案选型 | 对比哪些替代方案、为什么选择该方案；须回应“为什么不用微调 / 为什么不用 RAG”这类问题。 | 1—1.5 页 |
| ③ 系统设计 | 架构图（必配）、模块划分、数据流。 | 1—1.5 页 |
| ④ 实现细节 | 关键技术点、踩过的坑与解法；这部分最能体现工作量。 | 2—3 页 |
| ⑤ 评估 | 测试集来源与规模、指标定义、结果表、与基线对比、参数对比实验。 | 2—3 页 |
| ⑥ 错误分析与局限 | 失败样例 ≥3 个，逐一归因，如数据噪声、过拟合、指令歧义、检索失败等。 | 1—2 页 |
| ⑦ 工程与伦理 | 成本、延迟、权限与隐私、数据许可、AI 使用声明。 | 0.5—1 页 |

### 数据与工具的相关要求

数据优先使用公开数据，报告须写明来源、规模、许可与清洗规则。网页参考数据包括 THUCNews、ChnSentiCorp、MSRA、人民日报、CLUENER2020、CMRC2018、CBLUE 类基准任务和 SQuAD；使用前须自行确认许可与下载可用性。金融方向可从公开披露渠道构造数据。

允许调用外部 API，费用自负；报告写明所用模型、调用量、单价与总花费估算。API Key 使用环境变量，不得写进代码或提交仓库，提交前自查。不得将隐私或未授权个人数据上传外部服务；医学、金融数据必须脱敏。

允许本地小模型 / CPU 方案。预算或算力受限可缩小数据规模，在报告中说明降级原因与影响，不因此扣分。

### AI 使用与贡献声明

鼓励用 AI 查文档、调试代码、生成样板、润色文字、做对比实验、互查错误。禁止用 AI 代写实验设计与结果分析，禁止编造数据、伪造日志或截图、抄袭代码与报告，以及将 API Key、隐私数据交给外部服务或写入提交物。

报告必须声明 AI 的使用范围与人工修改部分。每人的贡献声明须写明负责模块与对应产出证据，与报告第⑧节一致；贡献声明相互矛盾且无法解释的，第⑥评分项相应扣分。
