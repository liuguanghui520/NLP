## 4. 各方法执行配置

| 方法 | 设备 | 模型运行精度 | 批量与线程 |
|---|---|---|---|
| TF-IDF＋逻辑回归 | CPU | scikit-learn Pipeline实际数据类型；不因公共配置字段就认定所有内部计算为FP32 | batch1，运行配置threads=4 |
| MacBERT | GPU | FP32 | batch1，运行配置threads=4 |
| Qwen零样本 | GPU | BF16 | batch1，运行配置threads=4 |
| Qwen固定少样本 | GPU | BF16 | batch1，运行配置threads=4 |
| Qwen普通LoRA | GPU | BF16 | batch1，运行配置threads=4 |

`threads=4`是运行配置，不是CPU只有4核，也不代表GPU只有4个执行线程。Qwen显式调用采用贪心解码、单束、最多8个新token、关闭思考；原模型默认采样参数不覆盖本次显式设置。

## 5. 正式延迟协议和数值

同一200条测试评论、同顺序、20条训练集评论预热、batch1串行。模型提前加载，计时包含分词、设备传输、前向/生成、标签解析；不包含模型加载和磁盘读取。GPU计时前后同步，分位方法linear。

| 方法 | 平均延迟ms | 各运行P95的均值ms | 运行数 |
|---|---:|---:|---:|
| TF-IDF（CPU） | 0.555 | 0.894 | 3 |
| MacBERT（GPU） | 6.133 | 10.668 | 3 |
| Qwen零样本（GPU） | 97.706 | 251.918 | 1 |
| Qwen少样本（GPU） | 79.414 | 100.536 | 1 |
| Qwen LoRA（GPU） | 59.056 | 70.277 | 3 |

训练路线先计算每个种子的延迟摘要再平均；“P95均值”不等于合并全部运行后计算的P95。CPU和GPU分别标明，用于本机实际部署方案比较。
