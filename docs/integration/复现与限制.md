# 复现与限制

本轮在现有本机WSL环境验收，不声称新机真实推理已通过，也不默认升级依赖。实际版本锁、源码提交与dirty状态分别见环境摘要和每次运行config.json。

三种验收须区分：已有预测重算（evaluate）、已有模型真实推理（predict/benchmark）与重新训练（train）。源码可从本仓库恢复；模型、适配器、Pipeline和评论正文不随仓库发布，下载链接尚未上传核验。缺资源时应报错，不能使用脱敏占位文本或换成其他模型。

新机步骤：获取仓库；按来源和SHA256获取Qwen/MacBERT基座及三个LoRA适配器、三个BERT优胜模型和三个TF-IDF Pipeline；按data/manifests获取并复建冻结数据；填写configs/paths.local.json；运行check和tests；导入或执行predict；最后evaluate、summarize、errors和plot。结果验收要求：已有预测重算各指标差异不超过1e-12，模型/数据/提示哈希精确匹配，ID顺序和真值一致。新训练不承诺逐样本完全一致。

LoRA普通SFT训练的原编排源码在src/legacy/lora，工具版本为独立LLaMA-Factory；统一CLI本轮只提供已验收的BERT/TF-IDF重新训练包装。提示路线无需训练。LoRA不新增未经验收的统一训练承诺；现有三个适配器通过统一predict接入。

历史指标与新评估协议分开。旧包曾按Accuracy选优且使用测试集，不再复制为Macro-F1最优结果。旧BERT代表错误数应为60，不是245；相同准确率不能证明逐条预测相同；不显著不能证明等效。partial为冻结底6层与学习率同时变化的组合对照。

提示包与本机通用JSONL的序列化哈希不同；冻结ID核对一致，导入核对真值，恢复提示核对全部验证输入哈希及四个训练示例正文哈希。包内不含其余训练正文，不能声称已逐字核对全量训练normalized_text；Alpaca哈希可与其manifest进一步对照。

成本口径：历史训练分项缺失保持null；BERT训练显存峰值可能含额外模型重载核验；附加整设备采样漏掉起始段；TF-IDF显存为不适用；新推理allocated/reserved为加载后测试/预热/延迟全阶段峰值，RSS仅期末值，不冒称采样峰值。绝不推算人民币成本或整机能耗。模型加载和磁盘读取不进入正式串行延迟。
