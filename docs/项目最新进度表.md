## 4. 下一步顺序与责任

1. **三人分别审查负责路线的结果和错例。** 输出观察、数据证据、归因可信度与局限；结果解释由学生本人完成。
2. **统一完成对比分析。** 汇总五方案效果、参数、稳定性、成本及样本级差异；成员C负责格式和统计整合，本人统筹，基线负责人确认基线证据。
3. **并行准备复现资源。** 各负责人整理本人路线产物、配置和校验和，提供合法可访问方式；检查链接和恢复流程，不公开密钥或未经授权正文。
4. **撰写报告并筛选图表。** 不把全部30张图堆入正文；主表、核心参数图、成本图、必要曲线及错例优先，其余附录或链接。
5. **执行新机真实复现。** 从仓库、README和公布资源开始，不依赖作者口头补充；失败修复后重新验收。
6. **Git发布、演示和打包。** 先核对文档迁移与公开范围；最终验收后合并、打标签、固定提交版本和提交清单。
