## 项目目录分工

```text
<project_root>/
├── README.md                    # 可运行命令与复现总入口
├── AGENTS.md                    # 仓库协作约束
├── docs/                        # 所有面向人员的文档，先看本索引
├── src/、scripts/、tests/        # 实现、调用和验收代码
├── configs/                     # 配置模板与冻结设置
├── data/                        # 数据清单与允许保留的数据资产
├── artifacts/                   # 模型、协议及最终产物关联清单
├── results/                     # 预测、指标、基准、汇总及本地产物
└── reports/                     # 程序审计与图表，不在本次整理中搬动
```

训练权重及大量原始日志仍保留个人工具工作区，不移动到docs。个人绝对地址由不提交的本地配置提供。

同一主题的历史副本不覆盖；`协作与融合交接/历史发布版本/`保留先前发布副本。integration中的交接副本作为执行时快照保留，不假定其与管理目录版本永远一致。
