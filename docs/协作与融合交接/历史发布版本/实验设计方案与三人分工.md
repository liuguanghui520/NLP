# 中文评论情感分析：完整实验设计方案与三人分工

整理日期：2026-10-23（北京时间）。

本文依据本聊天中本人已确认的实验选择整理，包含实验配置、统一评估规范、记录要求、验收与三人分工。不包含实验结果，不代表训练、评估或真实模型兼容性验收已经完成。成员B、成员C为占位称谓，正式提交前填写姓名。

## 1. 研究目标与实验矩阵

在本机 RTX 4070 Laptop、8GB 显存上串行运行，比较中文评论情感二分类方案的分类效果、训练成本、推理成本与稳定性。

| 路线 | 模型与训练方式 | 配置对照 |
|---|---|---|
| 传统基线 | 字符 n-gram＋TF-IDF＋逻辑回归 | 6组参数 |
| BERT基线 | 采用 MacBERT-base 配置，全部权重随机初始化，复用现成分词器 | 4组参数 |
| 原始Qwen零样本 | Qwen3-1.7B，无提示示例 | 固定提示 |
| 原始Qwen少样本 | 同一原始模型，正负各2条训练集示例 | 固定4条示例与顺序 |
| LoRA | 同一Qwen基座，普通LoRA，推理不放示例 | r=8、16 |

BERT路线命名为“采用 MacBERT-base 配置的随机初始化 BERT”，不称为预训练 MacBERT 全参微调。不额外进行无监督预训练。

统一按验证集 Macro-F1 选优。BERT与Qwen比较属于完整方案比较，不将差异全部归因于训练方式。“LoRA后无示例提示推理”表示推理提示没有示例，该模型仍接受过有标签训练。

本实验主要观察原始模型加入提示示例后的变化，以及相同无示例提示下LoRA前后的变化；不包含LoRA后少样本提示这一组合。

## 2. 数据、输入与指标规范

### 2.1 数据锁定与核验

- 使用 ModelScope `AiNiklaus/ChnSentiCorp`，来源为 [数据集页面](https://www.modelscope.cn/datasets/AiNiklaus/ChnSentiCorp)。
- 开跑前记录实际 revision、文件 SHA256、许可说明、标签定义和各划分数量；保留来源已有的训练、验证、测试划分。
- 缺少划分、标签不明或发现跨集重复时暂停，由本人确认处理，不擅自重划分或删除样本。
- 保留原始文本与稳定样本ID。核查空文本、缺失字段、重复文本及标签冲突，形成数据核验报告。
- TF-IDF只在训练集拟合；提示示例只来自训练集；测试集不参与调参、提示修改、示例选择或检查点选择。

### 2.2 文本与长度

- 统一换行符、去除首尾空白，不删除否定词、标点或表情。
- 所有路线先取前512个 Unicode 字符。
- BERT输入上限512 token，包含特殊符号。
- Qwen总输入上限2048 token，包含任务说明与示例；额外超限时仅从待分类评论尾部截断，保留完整任务说明与示例。
- 逐样本保存实际输入、长度与截断状态；传统基线使用完整512字符前缀。
- 字符限制与token限制分别统计，报告各路线实际输入差异，不能声称所有模型最终接收完全相同的正文。

### 2.3 少样本示例

- 排除空文本、重复文本和超长示例。
- 从正文不超过80字符的训练样本中按种子42抽取正负各2条，固定为负、正、负、正顺序。
- 保存示例ID、原文、标签、顺序与提示全文；锁定后正式运行不更换。

### 2.4 统一指标

| 项目 | 统一口径 |
|---|---|
| 标签 | `0=负面、1=正面`，先核实源数据映射 |
| 主指标 | Macro-F1；验证集用于选优 |
| 辅助指标 | Accuracy、正负两类 Precision/Recall/F1、混淆矩阵 |
| 零除 | 记0 |
| 非法输出 | Qwen原始输出去除首尾空白后，只有`0`或`1`合法；其余标记非法 |
| 非法输出计分 | 计入总样本数并视为错误；构成真实类别的漏判；另报非法输出率 |
| 不完整运行 | 基础设施失败导致预测不完整时，不发布完整测试指标；保留失败及关联重跑记录 |
| 最终报告 | 各训练路线优胜配置报告3个种子的单次成绩、均值与样本标准差 |

混淆矩阵须展示非法输出数量或增加“非法输出”预测列，避免统计时遗漏这部分样本。所有指标由同一个评估入口从逐样本预测重算。

## 3. 各路线训练与推理设置

### 3.1 字符 n-gram＋TF-IDF＋逻辑回归

- 使用 scikit-learn Pipeline。
- TF-IDF固定字符 n-gram=(1,2)、L2归一化、不使用停用词表、不限制特征数。
- 逻辑回归使用L2正则、`lbfgs`、`max_iter=2000`、不加类别权重。
- Optuna穷举 `C∈{0.1,1,10}` × `min_df∈{1,2}`，共6组。
- 未收敛则标记并保留警告，不静默增加迭代上限。
- 保存最终训练/验证log-loss和迭代次数，不伪造逐步loss曲线。

### 3.2 随机初始化BERT

- 固定 `hfl/chinese-macbert-base` 的架构配置及分词器版本，输出头为二分类。
- 只复用配置、词表与分词规则，不加载预训练模型权重；编码器、嵌入层和分类头全部训练。
- Optuna穷举学习率 `{1e-4,3e-4}` × 权重衰减 `{0,0.01}`，共4组。
- AdamW、线性学习率衰减、warmup比例0.1、有效批量16、梯度裁剪1.0。
- 微批量4、梯度累积4。
- 最多20轮，每轮验证；连续3轮验证Macro-F1未严格提高则早停，恢复最佳检查点；同分保留较早检查点。
- 保存真实分类loss、学习率、验证指标、训练步与时间。

### 3.3 原始Qwen零样本与少样本

- 使用 `Qwen/Qwen3-1.7B`，锁定同一基座版本和聊天模板。
- 关闭思考模式，使用贪心解码，最多生成8个新token。
- 零样本任务说明固定为：判断评论整体情感，仅输出`0`表示负面、`1`表示正面。
- 评论作为待判断数据放入明确边界内；少样本版本只增加已锁定的4组示例。
- 保存每条实际提示、原始输出与解析结果，不通过宽松解析掩盖非法输出。

### 3.4 普通LoRA

- 使用与提示实验相同版本的Qwen基座。
- 采用相同任务说明及训练集标签，训练输入不放示例，仅对答案计算训练损失；其余基座参数冻结。
- 比较r=8、16，alpha=2r，固定缩放比例；仅注入`q_proj`、`v_proj`，dropout=0.05。
- 固定3轮、学习率1e-4、AdamW、权重衰减0、warmup比例0.1、线性学习率衰减。
- 有效批量16；微批量1、梯度累积16，启用梯度检查点。
- 每轮验证，选择验证Macro-F1最佳检查点参评；推理不放示例。
- 训练优先使用BF16，先检查硬件与软件支持；不支持时暂停确认精度调整。
- 不得静默改用QLoRA、较小基座或其他注入模块。

### 3.5 搜索、种子与预算

- 首轮统一种子42，每个配置运行1次。
- 各训练路线在验证集选优后，补跑种子43、44，首次运行计入3次。
- 正常预算：传统基线8次拟合、BERT6次训练、LoRA4次训练，共18次；冒烟测试、失败和重试另记。
- 不按测试集挑选种子。逻辑回归可能几乎不随种子变化，应如实展示。
- 验证集同分时依次选择更低复杂度、预先固定配置顺序；配置顺序在运行前写入配置清单。
- 提示推理采用确定性设置，不用重复相同推理冒充独立随机实验。

## 5. 记录、成本与展示规范

### 5.1 运行与迭代记录

每次运行生成唯一`run_id`，保存完整配置、命令、代码版本、依赖、硬件、种子、数据和模型版本、提示全文、示例ID、stdout/stderr、检查点信息、逐样本预测与状态。

状态区分成功、失败、中断、OOM和重试；重跑不覆盖旧记录，保存父运行编号及重试原因。迭代记录包含修改内容、修改依据、所用反馈来自训练集/验证集/测试集中的哪一部分，以及复验结果。

### 5.2 延迟与资源

- 使用固定种子选出的同一批最多200条测试样本及相同顺序；保存样本ID清单。
- 预热20条，batch=1、串行、模型已加载。
- 计时包含分词、设备传输、推理和标签解析；不包含磁盘读取与模型加载。
- GPU计时前后同步，报告P50、P95、均值及吞吐。
- 报告训练总时长、验证耗时、最佳检查点耗时、峰值GPU allocated/reserved、设备采样显存、峰值进程内存、总参数与可训练参数、产物大小。
- CPU路线显存标为不适用。设备采样显存与进程内精确峰值分别标注，不混用。
- 区分搜索、补充种子、最终推理、失败重试成本；记录CPU/GPU小时。
- 没有电量或电价依据时不虚构人民币费用，也不将本地成本写成零。
