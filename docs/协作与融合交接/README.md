- 模型使用说明、训练操作说明、LoRA参数清单和冻结记录保留原处。

- 旧文档中提到上述交接文档在根目录的说法属于迁移前位置；同类文档以本索引的新位置为准。
- 本索引只更新文档位置，不宣称其中拟定目录、Git步骤或验收已经执行。旧方案与新确认不一致时，应结合日期、本人确认及运行证据，不直接执行历史待办。
