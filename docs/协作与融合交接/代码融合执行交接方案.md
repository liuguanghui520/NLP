## 3. 已确认的实验与指标口径

- BERT为预训练MacBERT全参微调，不再称随机初始化；partial保留为部分微调组合对照，不作为全参代表。
- 保留新包BERT 8组、TF-IDF 4组对照；数据量曲线及批处理对照作为历史扩展实验，融合不自动全部重跑。
- 验证集Macro-F1选优，Accuracy辅助；每个BERT运行保留验证Macro-F1最佳轮次，同分保留较早轮次。
- 训练种子42/43/44全部报告；数据划分种子67，冻结train6210、validation776、test777与各ID清单。
- 主指标Macro-F1，另报Accuracy、两类Precision/Recall/F1、weighted-F1、混淆矩阵、非法输出率；三种子报单次、均值、样本标准差。
- Qwen输出strip后严格为0/1才合法，非法计错并构成真实类别漏判；不删除非法记录后给主成绩。
- OOM、超时、运行失败及缺失预测与格式非法分开；基础设施失败不发布完整主成绩。
- 暂不增加PPL。loss含义不同须分图展示，不跨模型比较原始数值大小。

本轮文件记录BERT len512测试Macro-F1为0.915182±0.003462，TF-IDF为0.861040±0。这是待统一审计的现有结果，不是融合程序可写死的期望答案。

## 6. 公共数据、预测与评估接口

已有核对表明三方划分ID一致；提示包与LoRA记录的Alpaca哈希一致，但通用JSONL哈希不同。先按ID核对text、normalized_text及label，再适配字段；不重新清洗、去重或划分。

统一预测必需字段：

```text
run_id, method, config_id, seed, sample_id, split,
true_label, parsed_label, raw_output, status,
model_id, checkpoint_id, source_artifact_sha256
```

另保存输入字符数、实际输入token数、截断前token数、字符/token截断标记、输出token数、提示ID/哈希、耗时及timing_scope。历史缺失值用null和原因标记，不把整批耗时重复填写成单条延迟，不伪造原始模型输出。

映射原则：label→true_label，prediction/pred_label→parsed_label，negative/positive显式映射为0/1，invalid→invalid_format。保留原始字段或来源映射说明。

评估要求：

1. 校验完整ID集合、重复、顺序及冻结真值；不能只验证行数或两两交集。
2. 格式非法计错，基础设施失败标记不完整。
3. 混淆矩阵统一真实0/1两行、预测0/1/非法三列；历史矩阵保留原始形式。
4. weighted-F1按评估集真实类别支持数加权，不能按训练分布加权。
5. 三种子分别计算，再汇总均值和样本标准差；不能先混合预测冒充三种子评估。
6. 配对统计复用新包工具前补真值一致性及非法输出兼容，明确差值方向、检验方法与多重比较说明；不显著不等于等效。

统一入口拟提供check/import/evaluate/benchmark/summarize/errors/plot及各路线train/predict能力。README中的具体命令只能在实现并验证后填写，不把此处能力名称冒充现有可运行命令。

- 汇总加载、训练、验证、保存、测试及总时长，说明边界重叠；分开搜索、补跑和重试总成本。

- 图表至少包含总效果表、三种子表、验证参数对照、成本表、真实loss/验证曲线、混淆矩阵及效果—成本图。
- 单步日志可用于整理时间轴，说明累计时间是否含验证、保存和加载；不把缺少的历史时间伪造成精确测量。
- 修正旧包错误数量和“同准确率即逐样本相同”等文字错误，旧报告仅作素材，不能直接作为融合后的结论。
