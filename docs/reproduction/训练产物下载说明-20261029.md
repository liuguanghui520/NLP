## 校验与解压

下载后先核对压缩包SHA256，再使用包内逐文件清单核查。下面是Windows PowerShell示例，只处理TF-IDF种子42，不启动模型：

```powershell
$taskItem = (Get-Content -LiteralPath artifacts/reproduction-downloads.json -Raw -Encoding UTF8 | ConvertFrom-Json).trained_artifacts | Where-Object { $_.method -eq 'tfidf' -and $_.seed -eq 42 }
$taskDirectory = Join-Path (Get-Location) 'artifacts/downloaded/tfidf42-001'
if (Test-Path -LiteralPath $taskDirectory) { throw '请使用新的下载目录，保留旧记录。' }
New-Item -ItemType Directory -Path $taskDirectory | Out-Null
$taskZip = Join-Path $taskDirectory $taskItem.archive
Invoke-WebRequest -Uri $taskItem.download_url -OutFile $taskZip
if ((Get-FileHash -LiteralPath $taskZip -Algorithm SHA256).Hash.ToLowerInvariant() -ne $taskItem.archive_sha256) { throw '下载SHA256不匹配。' }
python scripts/package_trained_artifacts.py --verify-archive $taskZip
if ($LASTEXITCODE -ne 0) { throw '压缩包逐文件核查失败。' }
Expand-Archive -LiteralPath $taskZip -DestinationPath (Join-Path $taskDirectory 'unpacked')
```

其他包从同一清单选择相应method和seed，使用全新目录。Linux下载后可在同目录用`sha256sum -c SHA256SUMS`核对9包，或使用跨平台Python核查命令。

每个包的推理文件位于`<artifact_id>/model/`。TF-IDF为pipeline.joblib；MacBERT包括完整权重、config和tokenizer；LoRA为adapter_model.safetensors与原adapter_config。训练超参数、标签、种子、验证选优与原测试记录保存在metadata及manifest。
