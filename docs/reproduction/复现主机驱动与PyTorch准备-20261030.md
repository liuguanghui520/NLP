# 复现主机驱动与PyTorch准备

日期：2026-10-30。适用目标：Windows 10／11 x64、WSL2 Ubuntu22.04、RTX4060 Laptop 8GB，使用提交包重新加载权重预测，不重新训练。具体Windows版本在驱动下载页按复现主机实际情况选择。

## 需要提供的两项资源

| 资源 | 获取位置 | 安装位置 |
|---|---|---|
| NVIDIA正式驱动 | [NVIDIA官方驱动下载](https://www.nvidia.cn/geforce/drivers/)；选择GeForce RTX40 Series（Notebooks）、RTX4060 Laptop GPU及实际Windows版本 | Windows宿主机 |
| PyTorch 2.14.1+cu130 | [PyTorch官方cu130索引](https://download.pytorch.org/whl/cu130/torch/)；本项目使用Python3.11、Linux x86_64对应的wheel | WSL原生文件系统中的独立虚拟环境 |

驱动需支持CUDA13运行时，CUDA13.x的兼容驱动下限为R580系列；选择明确支持目标显卡与操作系统的正式版本，最终以CUDA／BF16实算预检通过为准。驱动不必与原机版本号相同。

没有需要单独安装的“CUDA13显卡”：显卡是硬件，驱动提供运行支持，PyTorch及其依赖提供CUDA用户态运行库。仅进行本项目已有权重推理，通常无需额外安装完整CUDA Toolkit或nvcc。

## 1. Windows安装驱动

1. 下载适合目标笔记本显卡和Windows版本的官方驱动安装程序。若当前驱动已满足要求并通过实算，无需重复升级。
2. 保存驱动版本、下载页面和安装文件SHA256，运行安装程序并按提示重启Windows。
3. Windows终端运行`nvidia-smi`，确认能够识别RTX4060 Laptop及驱动版本。

WSL使用Windows提供的GPU驱动接口，不在Ubuntu中另外安装Linux NVIDIA显示驱动。`nvidia-smi`中的CUDA Version表示驱动支持能力，不等于当前Python环境实际使用的CUDA运行库版本。

驱动安装涉及宿主机管理员权限，由复现主机使用者完成。此文档没有替对方执行安装。

## 2. WSL安装固定PyTorch及完整依赖

先按提交包README创建Python3.11.17独立环境，放在`/home/...`等WSL原生目录；LLaMA-Factory也放在WSL原生目录，并检出README指定commit。避免把虚拟环境或框架放在`/mnt/c/...`下：本次独立复现曾在该位置导入超时，移至WSL原生目录后通过。

激活新环境后，在提交包解压根目录执行以下命令。其中`/home/yourname/LLaMA-Factory-nlp`须替换为自己按README准备的框架目录：

```bash
python -m pip install --extra-index-url https://download.pytorch.org/whl/cu130 "torch==2.14.1+cu130" -r src/project/requirements.integration.lock -e /home/yourname/LLaMA-Factory-nlp
python -m pip check
```

这条命令在原冻结清单之外显式指定cu130构建，其他依赖仍按完整冻结清单安装。不要只装torch后跳过项目依赖，也不要按普通教程顺便更新torchvision、torchaudio或Transformers。保留安装日志；若依赖解析失败，保留错误，不自行放宽版本。

需要离线交付时，须在匹配的Linux x86_64／Python3.11环境中下载完整冻结依赖及所需构建依赖，并另行准备固定框架源码。单个torch wheel不是完整离线环境。此说明提供官方来源和安装步骤，尚未制作或验证完整离线安装包。

## 3. 实际检查GPU与BF16

在新环境中运行：

```bash
python - <<'PY'
import torch
print('PyTorch:', torch.__version__)
print('CUDA runtime:', torch.version.cuda)
assert torch.__version__ == '2.14.1+cu130'
assert torch.version.cuda == '13.0'
assert torch.cuda.is_available(), 'CUDA不可用，请检查宿主机驱动和WSL'
print('GPU:', torch.cuda.get_device_name(0))
assert torch.cuda.is_bf16_supported(), '当前环境未通过BF16支持检查'
x = torch.ones((2, 2), device='cuda', dtype=torch.bfloat16)
y = x @ x
torch.cuda.synchronize()
assert torch.equal(y.float().cpu(), torch.full((2, 2), 2.0))
print('CUDA/BF16 actual computation passed')
PY
```

这只是环境检查，不代表模型质量或主结果复现已通过。
