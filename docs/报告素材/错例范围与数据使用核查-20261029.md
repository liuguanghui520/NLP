|---|---|---|

**数量口径：**11个测试运行的错误并集为402条去重评论、1118个错误“样本—运行”组合；20条是人工试标，382条是AI辅助标注。124条待复核包括73条标签分歧、45条判断不确定、6条输入可见性问题；20条试标中含1条标签分歧。九例分析不等于402条全部人工确认。

**报告使用规则：**九例用于定性分析，覆盖五类失败，满足“≥3类错误归因”的内容要求。已有AI归因数量表可保留为探索性附录，注明来源和待复核状态，不写成最终人工归因比例，不据此推算“包含某现象的所有评论有多少会出错”。正式效果仍使用全部777条测试评论的源标签，非法输出规则、模型预测及三种子汇总均不改变。

## 3. 本项目不额外脱敏，明确记录实际处理

本轮对保留的全部7,763条评论原文进行了规则扫描，覆盖连续手机号、常见固定电话、邮箱、18位身份证候选及明确账号格式；对命中的9条评论作了AI上下文核对：

## 4. SwanLab实际记录范围

本轮读取了最终LoRA种子42／43／44的三个本地SwanLab备份，共7,638条可解析记录，CRC均通过；每个运行含31个指标字段、444条终端Log。实际指标包括训练loss、学习率、梯度范数、步数、训练时长与吞吐、验证Macro-F1／Accuracy／非法率／耗时，以及CPU、内存、GPU、磁盘和网络监控。

配置记录含训练、模型及LoRA参数；环境元数据的字段包括命令、工作目录、主机名、Python、CPU／GPU、内存和Git信息。三个配置中的API密钥字段为占位符，相关通知secret为空；本轮不读取登录文件，也不复制原始配置和完整终端日志。

对这些备份和配置，检查了不少于16字符的完整可见评论、32字符前缀，以及模型可见评论中本轮规则命中的联系方式，均未匹配到；也没有匹配到`training example:`标记。安装框架的预处理代码确实能打印样例，但它可能发生在SwanLab初始化之前，不能仅凭这段代码断言正文已上传。实际自定义验证回调上传的是分类指标，逐样本预测另存本地JSONL。

**可写入报告：本地备份核查未发现上述评论正文或联系方式匹配，不能写“云端只记录指标”。**LoRA实际配置为cloud模式，备份也包含终端、配置和环境信息；本次未登录云端检查远程当前保留内容、账号可见性或其他历史运行。零／少样本归档脚本中的SwanLab模式为offline，与LoRA分别说明。[官方集成说明](https://docs.swanlab.cn/guide_cloud/integration/integration-llama-factory.html)用于解释功能，实际范围以本次读取的安装版本和既有备份为证。

查证：[三个运行字段级审计](../../reports/data/data-usage-audit-20261029-04/swanlab-audit.json)。其中只保存指标名、元数据字段、计数、匹配ID及文件SHA256，没有保存正文、密钥或完整日志。
