## 启动与使用

在项目根目录的PowerShell执行：

```powershell
.\scripts\start_demo.ps1
```

该脚本使用本机已有WSL环境和模型，预加载Qwen3-1.7B普通LoRA T01种子42，不重新训练、不安装或升级依赖。各成员需先按`configs/paths.example.json`填写自己的`configs/paths.local.json`，并指定自己的`-WslUser`、`-Python`等启动参数；个人框架地址不写入共享目录结构。当前后端使用原工具工作区的selection与权重，Release下载到新目录后的路径对接另验收，不能把本机演示当作新机复现通过。

打开`http://127.0.0.1:8017/`即可输入评论、选择方案、查看标签、原始输出和单条耗时。首次切换方案包含模型加载等待，页面分别显示加载与推理时间；只保留一个GPU模型。连续切换零／少样本／LoRA可能需要数秒重新加载，录前彩排即可，不隐藏或伪造等待。

服务只监听127.0.0.1，端口8017；Ctrl+C停止自己的启动终端。日志位于全新`results/demo/<run_id>/`，请求写入`server/requests.jsonl`。不要将账户凭据粘贴到评论框。
