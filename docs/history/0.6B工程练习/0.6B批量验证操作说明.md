# 0.6B批量验证操作说明

日期：2026-10-25。用途：工具体验，比较原始Qwen3-0.6B与20步LoRA适配器；不计入正式1.7B实验。AI辅助实现与检查脚本，学生手动执行并解释真实结果。

## 运行

先在WebUI的Chat页点击“卸载模型”，释放显存；网页和启动终端可以保留。另开Ubuntu终端执行：

```bash
/home/lgh/.venvs/llamafactory/bin/python -u /mnt/c/Users/lgh/Documents/ChatGPT/NLP/scripts/evaluate_qwen06.py
```

Windows PowerShell也可直接运行同一入口：

```powershell
wsl -d Ubuntu -u lgh -- /home/lgh/.venvs/llamafactory/bin/python -u /mnt/c/Users/lgh/Documents/ChatGPT/NLP/scripts/evaluate_qwen06.py
```

两条命令任选一条，不要同时运行。原始模型base先运行，进程退出后运行lora；每种776条，每25条显示进度。完成前保持评估终端开启。

## 固定设置

- 验证输入：冻结v1-20261023的validation.jsonl，776条，哈希必须与原manifest一致；不读取test。
- 基座：/home/lgh/models/Qwen3-0.6B。
- 适配器：/home/lgh/LLaMA-Factory/saves/Qwen3-0.6B-Base/lora/train_2026-10-24-00-00-09。
- 使用本机LLaMA-Factory ChatModel、qwen3模板、关闭思考、BF16、不量化、batch1、贪心、最多8个新token、repetition_penalty=1.0。
- 用户消息为冻结任务说明、换行和评论正文；答案不进入提示。共享正文先保留冻结512字符，再按模板编码，超2048输入token时仅从正文末尾逐字符缩短；记录实际提示与是否再次截断。
- 每条独立消息，不带对话历史。仅strip后精确为0或1才接受；其余保存为invalid并计入错误、真类FN和整体分母。指标固定两个类别，混淆矩阵另列invalid。

## 输出与验收

项目results/qwen06-validation/下自动创建带时间和随机后缀的run_id目录，不覆盖旧结果。开头打印完整RUN DIRECTORY。

每种模型保存predictions.jsonl、metrics.json、推理配置和状态；父目录保存两份终端日志、comparison.json、源文件SHA256及依赖版本、nvidia-smi与运行状态。逐样本结果含评论正文，仅本地保留。当前脚本不向SwanLab上传验证结果，SwanLab原训练曲线仍用于核对训练过程。

末尾打印base/lora两行：count、accuracy、macro_f1、invalid_rate。两者都完成776条且父目录status.json为completed，才算本次完整验证完成。异常或中断保留日志与部分预测，不输出完整集比较结果；重新运行创建新run_id，记录与失败目录的重试关联。

记录的generation_call_seconds仅为同步后的model.chat调用时间，排除脚本预编码和加载；无固定预热，不作为正式延迟基准。显存峰值统计在加载后重置，只表示推理阶段，不能当训练峰值。
