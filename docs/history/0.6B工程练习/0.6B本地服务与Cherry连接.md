## 第一步：启动服务

先在WebUI Chat页卸载模型，等待训练和验证都已退出。在Windows PowerShell运行：

```powershell
wsl -d Ubuntu -u lgh -- bash /mnt/c/Users/lgh/Documents/ChatGPT/NLP/scripts/serve_qwen06.sh
```

保持此终端开启。看到Uvicorn running on http://127.0.0.1:8000后再继续。Ctrl+C停止服务，客户端随之无法调用；不需要另开WebUI模型。

此脚本使用LLaMA-Factory的HuggingFace后端，原始Qwen3-0.6B加选中适配器，BF16、普通LoRA、不量化、qwen3模板、关闭思考，仅监听127.0.0.1。默认贪心、最多8新token；客户端发送的生成参数可能覆盖默认值，演示设置与正式评估分开记录。

项目results/qwen06-api/<run_id>/保存启动时间、适配器路径、设置、启动脚本副本和服务日志；正常返回时记录退出码及结束时间。服务尚待用户手动启动验收。

## 第二步：检查Windows能否访问

另开Windows PowerShell执行：

```powershell
Invoke-RestMethod -Uri 'http://127.0.0.1:8000/v1/models' -Headers @{Authorization='Bearer qwen06-local-demo'}
```

应返回data，其中模型id为qwen3-0.6b-lora。若连接失败，先保留服务终端输出排查，不直接修改监听为公网或关闭防火墙。
