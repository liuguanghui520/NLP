## 手动运行

先在WebUI Chat页卸载模型。确保上一轮评估已经结束；不同时运行其他GPU训练或推理。新开Windows PowerShell：

```powershell
wsl -d Ubuntu -u lgh -- /home/lgh/.venvs/llamafactory/bin/python -u /mnt/c/Users/lgh/Documents/ChatGPT/NLP/scripts/tune_qwen06.py
```

保持终端开启。流程为rank8训练20步→验证776条→rank16训练20步→验证776条→保存比较及SwanLab汇总。每次新建适配器；不接着之前的20步适配器训练。不需要在WebUI点击开始。

默认沿用已有SwanLab登录，cloud模式。项目nlp-qwen06-experience中新增两个trial训练实验，另有以-summary结尾的验证汇总实验。训练实验查看loss/学习率；summary实验查看validation/macro_f1、validation/accuracy、validation/invalid_rate以及lora/rank。汇总图横轴是trial记录步，不是训练步。

若需要离线使用，用户可明确在命令末尾添加--swanlab-mode offline；此时日志本地保留，不会出现在云端页面。默认脚本不会静默切换离线模式。SwanLab汇总上传失败会记录错误，本地指标和Optuna数据库仍保留。

## 变量与固定项

| 参数 | trial 0 | trial 1 |
|---|---|---|
| lora_rank | 8 | 16 |
| lora_alpha | 16 | 32 |
| 目标模块 | q_proj,v_proj | q_proj,v_proj |
| dropout | 0.05 | 0.05 |
| 学习率/种子 | 0.0001 / 42 | 0.0001 / 42 |
| 微批量/累积 | 1 / 1 | 1 / 1 |
| 最大训练步 | 20 | 20 |

其他固定项：Qwen3-0.6B原始模型、qwen3模板、BF16、AdamW、weight_decay=0、linear调度、warmup_steps=2、gradient_checkpointing=True、训练输入上限2048 token，关闭思考。max_steps覆盖配置中的3轮设置。每个候选仅1次种子运行，属于工具体验，不提供多种子结论。

Optuna用GridSampler和两个明确排队候选依次执行，共2次，不使用TPE或剪枝；该范围内是穷举比较。目标为最大化验证Macro-F1，同分优先rank8。验证复用evaluate_qwen06.py，保持贪心、最多8新token、严格0/1解析、非法输出计错等口径。

- /home/lgh/LLaMA-Factory/project-workspaces/qwen06-optuna/<run_id>/：各trial的train.yaml、train.log、适配器/checkpoint、SwanLab训练本地日志。
- manifest记录用户确认、脚本/数据/权重哈希、依赖、上游代码版本、硬件和AI辅助用途。模型原始下载revision未知，保留该事实，以本地文件哈希锁定本次输入。

每次运行创建新的run_id；不覆盖旧数据。失败trial保留FAIL，目标值为空，不伪造零分；继续执行另一个候选。只有两组均COMPLETE、各验证776条，才标记完整比较completed；否则标记incomplete，用户查看错误后再决定重试，新运行须与旧失败记录关联。
