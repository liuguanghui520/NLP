## 记录内容与边界

工具工作区为/home/lgh/LLaMA-Factory/project-workspaces/qwen17-profile/<run_id>/，保存入口源码副本、训练配置、checkpoint、验证逐条预测、SwanLab本地记录，以及resource-record/console.log、resources.csv、status.json。

项目results/qwen17-profile/<run_id>/保存配置与manifest、模型文件哈希、运行状态，以及训练结束后复制的时间、参数量、验证历史、最佳检查点、资源汇总。原始数据和上游软件不修改；重跑独立run_id。

| 记录 | 实际含义 |
|---|---|
| wall_seconds | 子训练进程启动至退出，包含模型加载、训练、分类验证和保存 |
| trainer_interval_seconds | Trainer开始至结束，不含初始模型加载，含保存和日志 |
| classification_validation_seconds | 各轮分类验证时间之和，包括提示编码、生成和预测文件IO |
| trainer_interval_minus_classification_validation_seconds | 上一项扣除分类验证后的区间，仍包括保存与日志，不能称纯GPU计算时间 |
| preceding_train_peak_allocated/reserved | 每个训练区间的PyTorch CUDA峰值，加载后及每轮验证后重置 |
| validation_peak_allocated/reserved | 分类验证区间的PyTorch CUDA峰值 |
| resources.csv | 约1秒采样设备总显存、利用率、功率、进程树RSS；包括设备上的其他进程 |
| sampled_device_energy_wh | 功率样本梯形积分估计，仅设备读数，非整机插座能耗；不足两点则为空 |
| allocated_gpu_hours | 本次占用一块GPU的端到端墙钟小时，非按利用率折算的GPU计算小时 |

不虚构电价或费用。RSS按进程树采样相加，共享页可能重复计算；设备显存采样不当作精确进程峰值。读取不到的功率保留空值/错误。

预算可以根据实测时间估算，但改变rank、注入模块、批量等后成本可能变化；不能把首轮耗时简单乘配置数当成全部实测。报告后续汇总各次真实运行、搜索/复验/失败成本，并由学生完成解释。
