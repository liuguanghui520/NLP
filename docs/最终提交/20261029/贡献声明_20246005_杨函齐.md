# 个人贡献声明

**项目名称**：中文酒店评论情感分析：传统基线、提示学习与模型微调的效果及成本比较

**学号**：20246005　**姓名**：杨函齐　**身份**：组员　**日期**：2026年10月29日

## 1. 负责模块与具体工作

1. 负责TF-IDF和MacBERT两条监督基线的实现与交付，将共享512字符前缀转换为稀疏特征或模型token输入，保持冻结ID、标签与划分一致。
2. TF-IDF使用训练集拟合词表和IDF，与逻辑回归封装为Pipeline；保留四组特征对照，比较字符与词n-gram、特征维度和验证Macro-F1，最终采用字符1—3 gram配置。
3. MacBERT加载中文预训练权重，编码器、嵌入层与分类头全部训练；保留八组配置对照，比较学习率、长度／batch、类别权重、训练轮数和部分冻结，按验证Macro-F1确定len512／lr2e-5配置。
4. 对两条最终配置分别保留42、43、44三种子运行及预测；保存实际参数、训练过程、逐轮验证、最佳检查点、拟合或训练时间，并在交付中区分验证选优与测试评价。
5. 配合统一工程接入与结果核查，提供原始基线代码、候选对照、三种子产物与日志，使监督基线能够和提示／LoRA采用同一指标比较。

### 技术核查与协作边界

TF-IDF核查特征拟合只使用训练集，保存130996维特征、36次迭代、最终训练／验证log-loss及Pipeline重载结果，不伪造逐步曲线。MacBERT核查102269186个参数全部参与训练，记录FP32、token长度、batch、学习率及逐轮验证成绩，分别恢复各运行验证最优检查点。

最终测试统一采用Macro-F1主指标，同时提供Accuracy和正负两类P/R/F1；保留三种子原始输出，避免只报最优种子。对长度与batch同时变化、部分冻结同时改变学习率等对照条件如实标记，不把组合实验解释为单因素因果证明。
